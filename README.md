# 🖥️ Meu Portfólio

Bem-vindo ao meu pequeno espaço na internet. 💾

Este é o meu portfólio pessoal, desenvolvido para reunir um pouco dos meus projetos, estudos, experiências e coisas que venho aprendendo durante minha jornada na programação.

O site foi criado com uma estética inspirada em **computadores antigos, interfaces retrô e sistemas operacionais clássicos**, misturando programação com um pouco da minha personalidade. 🖱️✨

## 💻 Sobre mim

Sou estudante de **Engenharia de Software** e atualmente estou focada principalmente no desenvolvimento com **Java**, além de estudar tecnologias para desenvolvimento web e bancos de dados.

Tenho interesse em desenvolvimento de software, programação, tecnologia e segurança da informação.

Estou constantemente criando pequenos projetos para colocar em prática o que aprendo, experimentando novas ideias e tentando transformar meus estudos em coisas que realmente funcionem.

## 📂 Projetos

Aqui você pode encontrar alguns dos projetos que desenvolvi durante meus estudos, incluindo aplicações em Java, projetos web, experimentos com JavaScript e outras ideias que fui transformando em código.

Este portfólio também possui algumas pequenas experiências interativas, como jogos, ferramentas e elementos inspirados em interfaces antigas.

A ideia é que ele seja mais do que apenas uma página com uma lista de tecnologias: quero que ele tenha personalidade e seja um projeto que também represente o meu processo de aprendizado.

## 🚀 Objetivo

Meu objetivo é transformar cada projeto em uma oportunidade para aprender alguma coisa nova e, aos poucos, construir uma base sólida para trabalhar profissionalmente com desenvolvimento de software.
